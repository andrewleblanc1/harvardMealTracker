# Icons

Drop one image per dining hall in this folder, named to match its `id` from
`app/page.js`, as a `.jpg`. (If you switch to a different format later,
update the extension in `app/Icon.js` to match.)

Expected filenames:

- annenberg.jpg
- adams.jpg
- cabot.jpg
- currier.jpg
- dunster.jpg
- eliot.jpg
- kirkland.jpg
- leverett.jpg
- lowell.jpg
- mather.jpg
- pforzheimer.jpg
- quincy.jpg
- winthrop.jpg
- fly-by.jpg

Until a file exists, the app falls back to a colored circle with the hall's
initial, so nothing looks broken in the meantime.
